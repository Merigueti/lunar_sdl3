# lunar_sdl3
This is a study-oriented project developed using modern C++ and the EnTT ECS library. Its primary goal is to explore and analyze the physics of the Super Mario World game. My plan is to contribute small portions of code on Sundays to keep the GitHub repository active. However, I do not intend to commit to completing the project.

# README (English)

# Mario Physics Study Project

This repository is a **study project** developed in **modern C++** using the **EnTT ECS library**.
The goal is to analyze and replicate aspects of *Super Mario World* physics, while experimenting with ECS architecture.

I plan to add small code updates on Sundays to keep the repository active.
⚠️ **Note:** This is not a production-ready or complete game project.
